# Real-Time Fire and Smoke Detection System

## Overview

A real-time computer vision system that detects possible fire and smoke using a webcam.

## Features

- Real-time webcam monitoring
- Fire detection
- Smoke detection
- Bounding box visualization
- Detection percentage
- Alert generation
- Automatic alert image storage

## Technologies Used

- Python
- OpenCV
- NumPy
